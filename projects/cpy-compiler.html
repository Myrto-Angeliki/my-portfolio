PROJECT 09

Compilers Course Project

A compiler written in Python that converts a program written in a custom language to RISC-V assembly.

About the project

The compiler takes source code in a custom language and translates it into RISC-V assembly. This involves representing source constructs and producing target instructions according to the compiler's translation rules.

The project provides practical experience with language translation and the relationship between high-level source code and instruction-level output.
