Compilers II Course Project

A compiler/translator that converts source code written in a custom object-oriented language into standard C code.

About the project

The translator processes a custom object-oriented source language and generates C code as its target representation. The project focuses on the transformation between two programming-language representations.

This work demonstrates concepts in parsing, language translation and code generation.
