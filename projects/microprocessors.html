Microprocessors Course Projects

Course work combining Python-based analysis of circuit signal probabilities and switching activity with the design of a custom CPU architecture in Verilog.

About the project

The project covers both software-based analysis and hardware description. Python programs were used for operations related to signal probabilities and switching activity, while Verilog was used to describe a custom CPU architecture.

It provides experience at the boundary between software, digital logic and computer architecture.
