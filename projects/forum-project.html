PROJECT 01

.NET Forum Project

A forum application backend built with .NET 10, following Clean Architecture principles and exposing a REST API. The solution separates concerns across Domain, Application, Infrastructure and API layers.

About the project

The project is structured around clear separation of responsibilities. The API layer exposes the application through HTTP endpoints, while the other layers isolate domain logic, application behavior and infrastructure concerns.

This project demonstrates backend development, API design and architectural organization in a modern .NET application.

Backend Documentation

Endpoint Method Action
/api/auth/register POST Create a new user
/api/auth/login POST Login an existing user
/api/auth/password PUT Change the password of an authorized user
/api/auth/token GET Refresh the user's token
/api/users GET List all users
/api/users/{userId} GET Get specific user details
/api/users/by-email?email={userEmail} GET Get specific user details
/api/users/by-username GET Get specific user details
/api/users/me/friends GET List the current user's friends
/api/users/me/status PATCH Update the current user's status
/api/users/me/email PATCH Update the current user's email
/api/users/me/username PATCH Update the current user's username
/api/users/me/friends/{friendId} DELETE Remove a user from the current user's friend list
/api/users/me/posts GET List all the posts created by the current user
/api/users/me/comments GET List all the comments made by the current user
/api/users/me/posts/{postId:int} DELETE Delete a specific post created by the current user
/api/users/me/comments/{commentId} DELETE Delete a specific comment made by the current user
/api/users/me/friend-requests/{senderId}/accept PUT Create a friendship between the current user and the sender of the friend request
/api/users/me/friend-requests/{senderId}/deny DELETE Remove a friend request from the current user's friend request list
/api/users/me/friend-requests/{recipientId} POST Create a new friend request from the current user to another one
/api/users/me/friend-requests/{recipientId} DELETE Delete the friend request sent from the current user to a different user
/api/users/{userId} DELETE Delete a user
/api/posts GET List all posts
/api/posts/{postId} GET Get a specific post's details
/api/posts/by-user/{userId} GET Get the posts created by a specific user
/api/posts POST Create a new post
/api/posts/{postId} PUT Edit an existing post by the current user
/api/posts/{postId}/comments/{commentId} GET Get the details of a comment under a specific post
/api/posts/{postId}/comments GET List all the comments under a specific post
/api/posts/{postId}/comments POST Create a new comment under a specific post
/api/posts/{postId:int}/comments/{commentId:int} PUT Update an existing comment under a specific post if it belongs to the current user
/api/posts/{postId:int}/comments/{commentId} DELETE Delete a comment under a specific post if it belongs to the current user
