PROJECT 08

Qt File Analyzer

A personal project for a multithreaded desktop file analyzer in C++ and Qt. File analysis is performed asynchronously so that the user interface remains responsive while processing.

About the project

The central design goal is responsive desktop software: potentially expensive file-analysis work is separated from the UI thread. Qt provides the desktop UI and application framework, while C++ handles the underlying processing.

This project demonstrates desktop development, concurrency concepts and practical C++/Qt programming.
