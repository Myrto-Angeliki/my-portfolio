PROJECT 01

Analog Filter Module

PCB design of an analog signal conditioning module with a Sallen-Key Low-Pass Filter and LDO regulator.

About the project

A custom 2-layer printed circuit board (PCB) designed in KiCad for sensor signal conditioning in embedded hardware systems. This module combines a low-noise 3.3V Low-Dropout (LDO) power regulator with a 2nd-order active Sallen-Key low-pass filter (fc ≈ 1.06 kHz) and a unity-gain buffer stage to attenuate high-frequency noise prior to Analog-to-DigitalConverter (ADC) sampling.
