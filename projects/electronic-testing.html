PROJECT 03

Electronic System Testing & Reliability

Course project focused on adding Built-in Self-Test (BIST) capabilities to a Circuit Under Test (CUT) using Verilog.

About the project

The project explores hardware testability by incorporating BIST logic into a circuit under test. The design is expressed at the RTL level using Verilog.

This work connects digital design with concepts in electronic system testing and reliability.
